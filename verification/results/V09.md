## 发现的问题（已提 issue #18）

`nanocode/llm/anthropic.py` 第 75 行 usage 累加：

```python
usage.input_tokens = (u.get("input_tokens", 0) + u.get("cache_read_input_tokens", 0)
                      + u.get("cache_creation_input_tokens", 0))
```

OpenRouter 的 Anthropic 端点显式返回 `"cache_read_input_tokens": null`；
`dict.get(key, 0)` 只在键缺失时兜底，键存在但值为 null 时返回 `None`，
`int + None` → `TypeError: unsupported operand type(s) for +: 'int' and 'NoneType'`，
整个运行崩溃。`openai_compat.py` 同类代码已用 `(u.get(...) or 0)` 写法，anthropic.py 漏了。

issue：https://github.com/mbaiagent/nanocode/issues/18（`bug` 标签）
